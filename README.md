# CompStat-Bench

**Validity-aware comparison of statistical estimates.**

Comparing two statistics is not the same as computing either one correctly. A larger raw
count, a higher published rate, or a bigger percentage can *reverse* once the two quantities
are placed on a common denominator — the share of *commuters* who drive alone ranks U.S.
states differently from the share of *all workers*, and the labour-force-participation rate
over a country's *whole population* ranks countries differently from the rate over its
*working-age* population. We call this the **denominator-flip trap**: two individually-correct
numbers yield a wrong comparison when their universes differ.

CompStat-Bench is a benchmark of comparison pairs built from official statistics (U.S. Census
ACS, World Bank, Eurostat), plus a **parse-then-check** method that uses a 7B LLM only to
identify which denominator a question asks for and then verifies comparability with a
deterministic symbolic checker, abstaining when the denominator cannot be reconstructed.

## Headline result

On *flip pairs* (whose ranking reverses under the correct denominator), LLM judges — direct,
chain-of-thought, or handed the exact counts — are wrong 45–55% of the time, no better than
ignoring the denominator. The parse-then-check method holds wrong-ordering at or near **0%**
across held-out geographies, an unseen indicator family, and two non-Census sources at three
geographic scales; a learned reranker drives it to **exactly 0%** at 80–100% coverage. Framed
as selective prediction, it is the only non-oracle approach that pins selective risk at 0%
while answering a useful fraction of pairs.

## Repository layout

```
src/
  frames.py            # Estimate / ComparisonFrame data model
  checker.py           # deterministic DIRECT / RECONSTRUCT / NOT_ANSWERABLE comparability logic
  fetch_census.py      # Census ACS fetch (needs CENSUS_API_KEY)
  fetch_worldbank.py   # World Bank WDI fetch (public)
  fetch_eurostat.py    # Eurostat demo_r_pjangrp3 fetch (public)
  build_benchmark.py   # CompStat-Bench construction + flip-pair mining
  parse_frames.py      # Qwen2.5-7B frame parser (picks the denominator)
  reranker.py          # learned reranker: frozen MiniLM + logistic regression
  llm_judge.py         # LLM-as-judge baselines (direct / CoT / meta-with-counts)
  pot_baseline.py      # Program-of-Thought baseline (sandboxed code execution)
  evaluate.py          # wrong-ordering / coverage metric (naive / method / oracle)
  selective_metrics.py # risk-coverage operating points, abstention targeting, Kendall-tau
  audit_gold.py        # stratified gold-label face-validity audit
config.yaml, recipes.yaml                 # Census families (transport B08301, employment B23025)
config_worldbank.yaml, recipes_worldbank.yaml
config_eurostat.yaml, recipes_eurostat.yaml
data/bench/
  compstat.jsonl              # Census benchmark (train/dev/test/test_ood splits)
  compstat_worldbank.jsonl    # World Bank labour-force-participation pairs
  compstat_eurostat.jsonl     # Eurostat old-age-dependency pairs
  selective_metrics.json      # computed risk-coverage / ranking metrics
  reranker.pkl                # trained reranker (frozen-embedding + logistic regression)
tests/
requirements.txt, setup.sh
```

Raw fetched tables (`*.parquet`) and intermediate model outputs
(`parsed_frames_*.jsonl`, `judge_*.jsonl`, `eval_*.json`) are **not** tracked; they are
regenerated by the pipeline below. The three `compstat*.jsonl` benchmarks and the trained
reranker **are** included so results can be reproduced without re-fetching or re-training.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

The LLM parser and judges use `Qwen/Qwen2.5-7B-Instruct` (GPU recommended; an NVIDIA L4 is
sufficient). The reranker uses `sentence-transformers/all-MiniLM-L6-v2` (CPU is fine).

## Reproducing the benchmark (optional — data is included)

```bash
# Census needs a free API key: https://api.census.gov/data/key_signup.html
export CENSUS_API_KEY=...        # entered by the user, never committed
python -m src.fetch_census
python -m src.build_benchmark            # -> data/bench/compstat.jsonl
python -m src.fetch_worldbank && python -m src.build_benchmark --config config_worldbank.yaml
python -m src.fetch_eurostat  && python -m src.build_benchmark --config config_eurostat.yaml
```

## Running the pipeline

```bash
# parse the requested denominator, then score wrong-ordering
python -m src.parse_frames --split dev
python -m src.evaluate --parsed data/bench/parsed_frames_dev.jsonl --split dev

# learned reranker (trains on the train split, then predicts)
python -m src.reranker --train
python -m src.reranker --predict dev
python -m src.evaluate --parsed data/bench/parsed_frames_reranker_dev.jsonl --split dev

# baselines
python -m src.llm_judge --mode direct --split dev      # also: cot, meta
python -m src.pot_baseline --split dev

# selective-prediction / ranking metrics across all splits
python -m src.selective_metrics

# gold-label face-validity audit
python -m src.audit_gold --per-stratum 4
```

Each module ships with a `--selftest` that runs offline.

## Comparability verdicts

Each pair is labelled **DIRECT** (the requested share is directly published),
**RECONSTRUCT** (it must be assembled from component counts), or **NOT_ANSWERABLE** (the
requested universe cannot be reconstructed from the available components). A correct system
answers DIRECT and RECONSTRUCT pairs and abstains on NOT_ANSWERABLE ones.
